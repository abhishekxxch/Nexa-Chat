# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Nexa-Chat.git
```

---

## Backend

```bash
cd Backend
npm install
npm run dev
```

---

## Frontend

```bash
cd Frontend
npm install
npm run dev
```
